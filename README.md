# 🌿 Greenora — Modern Garden Design Landing Page

Greenora is a **single‑page website** themed around modern garden and landscape design.  
The project focuses on a clean layout, soft colors, and a smooth user experience.

---

## 🔗 Online Demo

View the live demo here:  
https://zahrazalife.github.io/Greenora/

---

## 📝 Description

Greenora is a modern landing page that showcases garden design services.  
The page includes sections such as **Home, Services, Portfolio, and Contact**, all designed with a minimal and nature‑inspired aesthetic.  
The layout is fully responsive and optimized for both desktop and mobile devices.

---

## 🛠️ Technologies Used

- **HTML5**  
- **CSS (Tailwind CSS)**  
- **JavaScript** (used lightly for the mobile hamburger menu)  
- **Responsive Design**
